# 🎨 Design System

The visual language of the Aureo VPN mobile app.

---

## 🎨 Color Palette

| Token | Value | Usage |
|-------|-------|-------|
| `gold` | `#F59E0B` | Primary accent, active states |
| `goldLight` | `#FBBF24` | Highlights, gradient starts |
| `goldDark` | `#D97706` | Pressed states, gradient ends |
| `cyberBlue` | `#06B6D4` | Secondary accent |
| `background` | `#030712` | App background (near-black) |
| `surface` | `#111827` | Cards, surfaces |
| `success` | `#10B981` | Connected state |
| `error` | `#EF4444` | Error state |

---

## 🔤 Typography

| Font | Weight | Usage |
|------|--------|-------|
| **Inter** | 400–800 | Body text, headings, UI labels |
| **JetBrains Mono** | 400–500 | IP addresses, stats, monospace data |

---

## 💎 Effects

- **Glass morphism** — Semi-transparent surfaces with blur (`rgba(255,255,255,0.05)`)
- **Gold glow** — Ambient gold shadow on primary elements
- **Animated transitions** — Spring-based enter/exit with stagger delays
