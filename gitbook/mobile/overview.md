# 📱 Mobile App Overview

Premium VPN experience for iOS & Android, built with Expo 54 and React Native.

---

## ✨ Features

- ⚡ **Quick Connect** — One-tap connection to the fastest, lowest-load node
- 🌐 **Server Browser** — Browse VPN nodes by country with real-time load indicators
- 📊 **Live Stats** — Real-time upload/download speed, data usage, connection duration
- 🗺️ **Country Selection** — Filter servers by country with flag icons
- 🔒 **Biometric Auth** — Unlock app with Face ID / Touch ID / fingerprint
- 🛡️ **Kill Switch** — Block all traffic if VPN connection drops
- 📡 **DNS Leak Protection** — Route DNS queries through encrypted tunnel
- 👤 **Connection Profiles** — Save & switch between preset VPN configurations
- 🔔 **Push Notifications** — Connection status alerts
- 🎨 **Premium Dark UI** — Gold-accented design with glass morphism effects
